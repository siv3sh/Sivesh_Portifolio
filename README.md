# Sivesh PB — Portfolio

Personal portfolio website for Sivesh PB, Junior AI Engineer.

## Stack

- React 19 + Vite
- Tailwind CSS v4
- Google Fonts: Syne (headings), Inter (body)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Deploy

The `dist/` folder after `npm run build` can be deployed to Vercel, Netlify, GitHub Pages, or any static host.
